# Lineup verwalten — für Camps

Ihr verwaltet euer Lineup selbst, direkt in der App. Ihr braucht dafür nur
euren **6-stelligen Camp-Code** — den habt ihr per Mail bekommen.

!!! danger "Der Code gehört euch allein"

    Ein Code schaltet **genau ein Camp** frei. Gebt ihn nicht weiter und
    schickt ihn nicht in Gruppenchats — wer ihn hat, kann euer Programm ändern,
    und jede Änderung geht sofort an alle, die eines eurer Sets markiert haben.

    Code verloren oder im Verdacht, dass er rumliegt? Meldet euch bei der
    Orga, dann bekommt ihr einen neuen.

## Die vier Schritte

1. **[Anmelden](anmelden.md)** — die versteckte Geste und der Code.
2. **[Timetable bearbeiten](timetable.md)** — Slots anlegen, besetzen, verschieben, B2B, No-Show.
3. **[Lineup pflegen](lineup.md)** — eure DJs anlegen und entfernen.
4. **[Veröffentlichen](veroeffentlichen.md)** — prüfen und live schalten.

Wenn etwas klemmt: **[Häufige Fehler](fehler.md)**.

## Das Wichtigste vorweg

!!! warning "Nichts wird gespeichert, bevor ihr veröffentlicht"

    Alles, was ihr ändert, ist zunächst nur ein **Entwurf auf eurem Telefon**.
    Er geht erst raus, wenn ihr unten auf **SPEICHERN & VERÖFFENTLICHEN**
    tippt und den Prüfen-Dialog bestätigt.

    Das ist gut — ihr könnt in Ruhe umbauen. Verlasst ihr den Bearbeitungsmodus
    mit ungespeicherten Änderungen, fragt die App nach (*Änderungen
    verwerfen?*). **Zwei Wege fragen nicht** — siehe
    [Häufige Fehler](fehler.md#entwurf-verloren).

!!! note "Die Anmeldung hält nicht ewig"

    Schließt ihr die App komplett, seid ihr abgemeldet und müsst den Code neu
    eingeben. Es gibt keine „angemeldet bleiben"-Funktion.

## Was eure Änderungen auslösen

Ändert ihr ein Set, das jemand mit ★ markiert hat, bekommt diese Person eine
Mitteilung. Der Prüfen-Dialog sagt euch vorher, wie viele das sein werden:

> ⚠ **3 geänderte Set(s) benachrichtigen ihre Favoriten.**

Deshalb: **sammelt eure Änderungen und veröffentlicht einmal**, statt fünfmal
hintereinander. Sonst wirkt euer Programm für die Leute wie ein Flackern.

Benachrichtigt wird bei: **abgesagt**, **als No-Show markiert**, **Zeit
verschoben**, und bei Änderungen an **wer spielt / B2B / Genres**. Ein
**komplett neues** Set löst keine Mitteilung aus — es konnte ja noch niemand
markieren.
